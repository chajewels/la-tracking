# Welcome to the Cha Jewels HUB

This is the in-app help center for the **Cha Jewels HUB**. It covers both the internal HUB at **app.chajewelsjp.com** and the customer portal at **portal.chajewelsjp.com**.

## What you'll find here

The Help Center is organized into four areas:

- **Quick Start** — step-by-step tutorials for your daily workflow
- **HUB Reference** — detailed feature documentation for staff, finance, CSR, and admin
- **Customer Portal** — guides for customers using the portal
- **Glossary, FAQ, Changelog** — supporting reference material

## Who sees what

Content is filtered by your role. You'll see only the sections relevant to your work. Admins see everything.

| Role | What you can see |
|---|---|
| Admin | All sections |
| Finance | Quick Start + HUB Reference (finance-relevant) |
| Staff | Quick Start + HUB Reference (staff-relevant) |
| CSR | Quick Start + HUB Reference (CSR-relevant) |
| Customer | Customer Portal sections only |

## Getting started

Pick a section from the left sidebar to begin. If you're new to the HUB, start with the **Quick Start** for your role.
